## 需要讨论的功能点

### A. 世界书注入模块重构
**问题**：当前世界书注入功能过于简陋，且多个模块（工具、填表工作台等）都需要用到。

**当前缺陷**：
- 选择好的世界书不能快捷取消（需要重新找到并取消勾选）
- 选择好的世界书不能选择注入哪些条目（当前是整本注入）
- 没有一键关闭所有条目 / 一键启用所有条目
- 没有预设化管理（不能保存/加载世界书组合配置）

**可能方案（待讨论）**：
1. **预设化**：像 API 预设那样，把"选中的世界书 + 条目筛选规则"存为预设，各模块绑定预设 ID
2. **直接增强**：在当前 UI 上加条目选择、快捷操作按钮，但不做预设
3. **混合**：基础功能直接增强 + 提供"保存为世界书配置"的预设功能

### B. 多标签提取 + 写回冲突
**问题**：提取配置中填入多行标签时，提取正常（多个标签都能提取到内容），但写回时会尝试把每个标签块的原有内容替换为新内容，导致其它不相关的原文内容被剔除。

**根因**：写回逻辑对每个标签做内容替换，多标签场景下替换范围互相干扰。

**可能方案（待讨论）**：
1. **只写回第一个标签**：多标签仅用于提取（给 AI 看），写回时只操作第一个标签的内容
2. **标记主写回标签**：UI 上让用户指定哪个标签用于写回，其余标签仅用于提取上下文
3. **追加模式**：写回不替换，而是追加到指定位置
4. **分标签写回**：每个标签独立写回各自的内容（需要 AI 输出也按标签分段）

## 最终目标布局结构

```
yyt-tool-panel
├── hero (sticky, 滚动时压缩)
│   ├── 工具名 + 描述
│   ├── chips (模式/预设/状态)
│   └── 按钮: 保存配置 + 立即执行一次
├── [可选] runtime 状态概览 (inline 行)
├── 绑定区 (flow-section)
│   ├── 输出模式 select
│   ├── API 预设 select
│   ├── Ai 指令预设 select (无开关)
│   └── 世界书注入 (待重构)
├── 配置区 (flow-section)
│   ├── 模板修改框 textarea
│   └── 提取配置 (标签/正则 + 最大消息数 + 测试提取按钮)
└── (无 footer, 无 macro-hint)
```
