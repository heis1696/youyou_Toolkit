# 交火模式关键词生成提示词（keywordPromptGroup）

> 来源文件：`Reference/shujuku-spv3.7/src/shared/defaults.ts`
> 触发场景：AI 生成前，向量索引召回流程中生成检索关键词
> 消息结构：3 段

---

## 消息 1 — system（不可删除）

```
你负责为交火模式纪要索引召回生成检索关键词。
你会看到最近对话上下文和当前用户输入。
目标：输出最相关的 12 个简洁关键词或短语，用于纪要索引召回与重排序。
优先级：人物、地点、时间、事件、目标、冲突、道具、组织、关系变化、未解决问题。

【输出格式 — 必须严格遵守】
你的回复必须且只能包含以下两部分，不得使用其他任何格式：

<thinking>
逐步分析最近上下文、当前用户输入、涉及人物、地点、时间、事件、目标、冲突、道具、组织、关系变化和未解决问题。
</thinking>
<keywords>关键词1，关键词2，关键词3</keywords>

【硬性规则】
- 关键词必须且只能放在 <keywords></keywords> 标签之间。
- 禁止使用"关键词："前缀输出，禁止使用编号或列表格式。
- <keywords> 标签内只放关键词或短语，不要放解释句、编号、前后缀说明。
- 多个关键词必须使用中文逗号分隔。
- 尽量输出 12 个，最多 24 个。
- <keywords> 标签外的任何内容都不会被用于检索匹配。
```

## 消息 2 — user（可删除）

```
最近上下文：
$RECENT_CONTEXT

当前用户输入：
$USER_INPUT

请根据以上内容生成交火模式纪要索引召回关键词。先在 <thinking> 中分析，然后在 <keywords></keywords> 标签中输出关键词。
```

## 消息 3 — assistant：预填充（可删除）

```
<thinking>
```

---

## 占位符

| 占位符 | 含义 | 数据来源 |
|--------|------|---------|
| `$RECENT_CONTEXT` | 最近 N 对对话 | `buildRecentContext_ACU(pairCount)`，格式为 `用户: 消息\nAI: 消息` |
| `$USER_INPUT` | 当前用户输入 | 运行时传入的 `userInput` |

## 关键词解析

AI 响应通过 `parseKeywords_ACU` 解析：
1. 优先从 `<keywords>` XML 标签提取
2. 回退从 "关键词：" 前缀提取
3. 按中英文逗号、顿号、分号、管道符分割
4. 去重，最多 24 个关键词

## 去重机制

8 秒内相同输入不重复执行关键词生成（`lastRuntimeSignature_ACU` + 8000ms 窗口）。
