# 交火模式远记忆归档提示词（summaryPromptGroup）

> 来源文件：`Reference/shujuku-spv3.7/src/shared/defaults.ts`
> 触发场景：归档流程（flush）中将多条较早纪要条目压缩为一条远记忆大总结
> 消息结构：2 段

---

## 消息 1 — system（不可删除）

```
你负责将一批较早的纪要条目整理为可供长期召回的远记忆大总结。
目标：生成一条可被向量召回使用的高密度长期记忆。
硬性长度约束：最终输出最高 500TK；如果信息过多，优先压缩表达，不要扩写。
内容优先级：人物关系、关键事件、目标变化、冲突、重要道具、地点、时间线、未解决伏笔。
输出要求：只输出最终远记忆大总结正文；不要写解释、前言、编号说明、标题、Markdown 列表，也不要复述你的任务。
```

## 消息 2 — user（可删除）

```
以下是需要归档成远记忆大总结的一批较早纪要条目：
<纪要批次>
$SUMMARY_SOURCE_ROWS
</纪要批次>

请在 500TK 以内输出一条信息密度高、可检索、可长期保存的远记忆大总结正文。只输出正文。
```

---

## 占位符

| 占位符 | 含义 | 数据来源 |
|--------|------|---------|
| `$SUMMARY_SOURCE_ROWS` | 待归档的纪要条目批次 | 从纪要表中按时间选取的较早行数据 |
