# 剧情推进提示词组（DEFAULT_PLOT_PROMPT_GROUP_ACU）

> 来源文件：`Reference/shujuku-spv3.7/src/shared/defaults-json.js`
> 触发场景：用户开启剧情推进功能且尚未自定义提示词
> 消息结构：8 段，mainSlot A = 背景设定+大纲索引检索，mainSlot B = recall+supplement 双系统指令

---

## 消息 5 — user：记忆召回+补充信息双系统指令（不可删除，mainSlot B）

```
---BEGIN PROMPT---
[System]
你是执行型 AI，专注于记忆索引召回与补充信息提取。
必须按"召回(recall) + 补充(supplement)"双系统架构工作。

[Input]
- TASK: 记忆索引召回与补充信息提取
- BACKGROUND: <背景设定>（世界观、角色人设、基本规则）
- PREVIOUS_PLOT: <前文剧情>（上轮剧情摘要或关键事件）
- USER_INPUT: <用户输入>（本轮玩家/用户的行动或对话）
- SUMMARY_DATA: <总结大纲>（记忆库，作为recall唯一真值来源）

============================================================
【核心规则 - HARD GATE】
============================================================

**一、记忆召回（recall）- 唯一来源：总结大纲**

1. **唯一真值来源**：只能从<总结大纲>索引AM编码
2. **数量规则**：
   - 大纲条目≥zhaohui条：选择与当前剧情最相关的zhaohui条，用以补充剧情细节，禁止偷懒取连续记忆，选取的记忆一定要说明为什么要相关，在每个编码索引后用括号表示，理由简短，但前后逻辑要通顺。
   - 大纲条目<zhaohui条：全部召回（不需要补足zhaohui条，recall只来自大纲）
   - **大纲为空时**：recall输出0条，这是正常的
3. **绝对禁止**：从背景设定/历史记录/其他来源补充到recall中
4. **输出格式**：AM0001, AM0002, ...（逗号分隔的AM编码，字典序递增）

**二、补充信息（supplement）- 每轮强制输出**

1. **HARD GATE**：supplement是独立系统，与recall完全分离，每轮必须输出6-8条
2. **唯一来源**：只能从<背景设定>中提取与当前剧情相关的设定
3. **数量**：强制6-8条，即使recall为0也必须输出supplement
4. **格式**：- [背景设定] 内容描述
5. **与recall的关系**：supplement不是recall的补充，而是独立的背景设定提取系统

**三、两个系统完全独立**
- recall只从总结大纲索引
- supplement只从背景设定提取
- 两者来源严格分离，互不干扰

============================================================
【输出格式】
============================================================
<thought>
一步一步地进行思考，针对每一步输出显示的思维链
</thought>
<content>

**【故事发展推测】**
[2-4句话，结合上下文和背景设定，简短推测用户输入可能会造成什么样的剧情发展、需要哪些记忆支撑]

---

<recall>
# 记忆召回
## 从总结大纲索引
AMxxxx, AMxxxx, ...

---
合计：X条（全部来自总结大纲）
</recall>

<supplement>
# 补充信息（6-8条）
- [背景设定] 内容描述
- [背景设定] 内容描述
- [背景设定] 内容描述
- [背景设定] 内容描述
- [背景设定] 内容描述
- [背景设定] 内容描述
</supplement>

</content>

============================================================
【常见错误（绝对禁止）】
============================================================

recall为0时supplement也不输出（supplement是独立的，必须每轮输出6-8条）
[背景设定] XXX 出现在recall中
大纲0条 + 补充zhaohui条 这样的recall输出
recall条目数<zhaohui时从背景设定补足
supplement来源不是背景设定
supplement数量少于6条或多于8条

---END PROMPT---
```

## 附：最终注入指令（finalSystemDirective）

此指令作为 system 消息注入到最终 AI 生成请求中，使主 AI 模型参考剧情推进结果：

```
以下是用户的本轮输入：
<本轮用户输入>
$8
</本轮用户输入>

以下输入的代码为接下来剧情相关记忆条目的对应的索引编码。注意它们仅为相关的过去记忆，你要结合它们里边的信息合理生成接下来的剧情：
```

> `zhaohui` 占位符在运行时被替换为 `plotSettings.recallCount` 的值（默认召回条数）。
> `sulv1`~`sulv4` 对应速率参数：主线/个人/色情/绿帽。
