# UI 重构宿主回归测试清单

> 本清单覆盖 UI_REFACTOR_PROGRESS.md 中 Phase 2–6 的关键验证路径。
> 所有测试需在真实 SillyTavern / TavernHelper 宿主环境中执行。

---

## Phase 2：Async 写回守卫（isContainerValid / renderSessionId）

### TC-2.1 面板切换后 async 回调不崩溃
- **步骤**：
  1. 打开工具箱，进入任意工具的配置面板
  2. 手动执行该工具（触发 async 写回）
  3. 在写回完成前切换到另一个主 Tab（如 API 预设）
- **预期**：无 JS 错误；写回完成后不会向已卸载的面板容器写入 DOM

### TC-2.2 renderSessionId 防止过期渲染
- **步骤**：
  1. 打开工具箱，进入小幽点评或本地变换工具面板
  2. 手动执行
  3. 在执行过程中快速切换到其他工具子 Tab 再切回
- **预期**：面板显示最新结果，不会出现上一次 session 的渲染残留

---

## Phase 3：Runtime / Structure 事件分离

### TC-3.1 工具执行不重建导航栏
- **步骤**：
  1. 打开工具箱，在工具页选择一个工具
  2. 手动执行该工具
  3. 观察左侧导航栏 / 子 Tab 列表
- **预期**：执行完成后导航栏不闪烁、不重建；运行状态标记正常更新

### TC-3.2 工具定义变更重建导航栏
- **步骤**：
  1. 在工具管理页新建一个自定义工具
  2. 观察工具页子 Tab 列表
- **预期**：新工具出现在子 Tab 中；原有 Tab 不受影响

---

## Phase 4：面板宿主生命周期

### TC-4.1 切换 Tab 正确卸载旧面板
- **步骤**：
  1. 打开工具箱，进入 API 预设页
  2. 切换到工具页
  3. 再切换回 API 预设页
- **预期**：每次切换后面板内容正确渲染；无 jQuery 事件堆积（通过控制台检查无重复事件绑定警告）

### TC-4.2 动态工具面板缓存为工厂而非实例
- **步骤**：
  1. 打开工具箱，进入一个自定义工具的配置面板
  2. 修改工具配置并保存
  3. 切换到另一个工具再切回
- **预期**：面板显示最新保存的配置，非缓存的旧实例状态

### TC-4.3 兼容 Tab 显示错误态而非 fallback
- **步骤**：
  1. 打开工具箱
  2. 检查原由 ui-components.js 渲染的 Tab（如有）
- **预期**：若 uiModule 路径加载失败，显示错误提示而非回退到旧兼容模块

---

## Phase 5：模块级状态清理

### TC-5.1 API 预设面板状态隔离
- **步骤**：
  1. 打开工具箱 → API 预设页
  2. 选择一个预设
  3. 关闭弹窗，重新打开
  4. 检查当前选中的预设
- **预期**：选中状态从容器实例读取，不残留上一次的全局状态

### TC-5.2 工具管理编辑弹窗容器作用域
- **步骤**：
  1. 打开工具管理页
  2. 点击编辑一个工具
  3. 在编辑弹窗中修改并保存
  4. 再次编辑同一个工具
- **预期**：编辑弹窗始终从 overlay 容器读取，不使用全局 `$('#...')` 选择器

### TC-5.3 Bypass 面板选择器容器作用域
- **步骤**：
  1. 打开 bypass（破限词）面板
  2. 切换不同的预设
  3. 关闭弹窗重新打开
- **预期**：读写选择器使用容器作用域的 class 选择器，非固定 ID

---

## Phase 6：兼容边界收缩

### TC-6.1 旧 public API 已移除
- **步骤**：
  1. 在控制台执行：`window.YouYouToolkit.getUiComponents()`
  2. 执行：`window.YouYouToolkit.getPromptEditor()`
  3. 执行：`window.YouYouToolkit.loadLegacyModule()`
- **预期**：三个调用均返回 `undefined` 或抛出"方法不存在"错误

### TC-6.2 内置工具 Sub-Tab 仅走 uiModule 路径
- **步骤**：
  1. 打开工具箱 → 工具页
  2. 逐个点击内置工具子 Tab
- **预期**：所有内置工具面板通过 `modules.uiModule` 路径渲染，不回退到 `ensureLegacyModule()`

## 回归守护

### TC-R.1 完整导航遍历
- **步骤**：
  1. 打开工具箱
  2. 依次点击所有主 Tab 和子 Tab
  3. 在每个面板停留 2 秒
- **预期**：无 JS 错误、无白屏、无导航栏闪烁

### TC-R.2 自动执行后 UI 不崩溃
- **步骤**：
  1. 启用自动执行
  2. 在聊天中产生一条 AI 回复
  3. 在自动执行进行中打开工具箱
- **预期**：弹窗正常打开；运行状态正确显示；面板不崩溃

### TC-R.3 构建验证
- **步骤**：
  1. 运行 `npm run build`
- **预期**：构建成功，无错误
